## Compatibility policy

Contract versions follow semantic-version intent:

- patch — clarification or compatible schema correction;
- minor — backward-compatible operation, tool, or optional-field addition;
- major — removal, rename, newly required input, incompatible type change, or changed side effect.

No public compatibility or deprecation SLA has been accepted yet. Until one is approved, the
changelog and an explicit human-reviewed release decision are required before customers should
treat a candidate as stable.

## Verify a downloaded specification

```bash
python -c 'import pathlib, yaml; p=pathlib.Path("incidentflow-mcp-openapi-0.1.0.yaml"); print(yaml.safe_load(p.read_text())["info"])'
```

Use a local copy of the YAML. Do not send customer tokens or request samples to an online schema
validator.
